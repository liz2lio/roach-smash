# ROACH SMASH!

ROACH SMASH! is a Python/Pygame arcade prototype where players smash moving
cartoon cockroaches using fast pointer movements. The pointer currently
simulates a physical fly swatter.

The game includes a 60-second timer, three lives, normal and golden roaches,
splat effects, and a high score saved between sessions.

## Current status

The mouse-based game has been tested and works. Physical camera tracking and
projector calibration are not yet connected or tested.

## Requirements

- Python 3.11
- Pygame

## Install and run

```bat
python -m pip install pygame
python main.py
